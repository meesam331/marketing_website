## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/meesam331/marketing_website.git
   ```
2. Open `index.html` in any web browser.
3. No build steps or external dependencies required!

---

## ⚙️ Customization

- **WhatsApp Order Number**: Open `index.html` and replace `923001234567` with your official WhatsApp business number.
- **Product Prices & Items**: Update the `.product-card` items and modal definitions in `index.html`.
- **Social Links**: Update Instagram and Facebook links in the floating buttons and footer.
