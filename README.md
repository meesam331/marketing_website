# Mrs Zeeshan — Handmade Beauty & Makeup

A beautiful, animated marketing website for **Mrs Zeeshan** — handmade beauty oils, skincare & makeup crafted in **Karachi, Pakistan**.

## Features

- Feminine rose-gold design tailored for girls & women
- Fully animated (particles, scroll reveal, 3D tilt, counters, custom cursor)
- Product showcase: oils, makeup, skincare & gift boxes
- WhatsApp & Instagram integration for easy ordering
- Karachi-focused delivery areas with nationwide shipping
- Mobile responsive

## Quick Start

Open `index.html` in any browser — no build step required.

## Customize

Update these in `index.html`:

- **WhatsApp number**: Search for `923001234567` and replace with your number
- **Instagram**: Update `@mrszeeshan.beauty` links
- **Email**: Update `mrszeeshan.beauty@gmail.com`
- **Product prices**: Edit the price tags in the Products section
